# MeetStream LangChain Integration

LangChain integration for using MeetStream meeting transcripts, recordings, and structured meeting data in AI applications.

## Status

This repository is being initialized. Implementation details, setup instructions, and usage examples will be added as the integration is built out.

## About MeetStream

MeetStream provides meeting bot infrastructure for joining online meetings, recording calls, generating transcripts, and extracting structured meeting data through developer-friendly APIs.

## Repository Scope

- LangChain components for loading and working with MeetStream meeting data.
- Examples for retrieval, summarization, and agent workflows using meeting transcripts.
- Documentation for installation, configuration, and API usage once available.
